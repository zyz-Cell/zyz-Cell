## 代表项目

### 农业机器人视觉导航系统

基于 **ROS2、Scout Mini与Intel RealSense D455**，开展农业行间连续视觉导航系统开发与实车调试。

- 实现道路中线提取与PD循迹控制。
- 融合RGB-D信息进行障碍距离估计与通行间隙判断。
- 结合双侧深度变化检测行末，采用状态机与Dubins轨迹规划完成绕障及自动换行。
- 相关功能已在实车跑通，项目论文正在撰写。

### 中国机器人大赛机器人项目

带队备赛，负责电控与视觉部分的开发和调试。

- 基于 **STM32与FreeRTOS** 开发底盘控制及外设通信模块。
- 基于 **ROS2与YOLO** 开发目标识别模块，对接视觉结果与下位机控制。
- 与队友协作排查通信、识别和运动控制问题，推进软硬件联调。
